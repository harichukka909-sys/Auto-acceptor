# Auto Acceptor

This repository contains a minimal Android application scaffold for a ride-acceptance dashboard that monitors Rapido, Uber, and Ola trip requests.

## Features
- Auto-accept mode toggle
- Live trip status panel
- Driver network indicators
- Ride acceptance action button
- Jetpack Compose UI

## Project structure
- `app/` — Android application source code
- `build.gradle.kts` — root Gradle settings
- `settings.gradle.kts` — project configuration

## How to run
1. Open the project in Android Studio.
2. Let Gradle sync the dependencies.
3. Select an Android emulator or device.
4. Run the app.

## Notes
This is a starter application designed for rapid customization and extension. If you want, the next step can be adding real ride APIs, Firebase, background automation, or a full driver dashboard.
